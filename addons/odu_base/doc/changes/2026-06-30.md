# 2026-06-30

A public **contact form** capability was added to `odu_base` to back the starter
website: a model to store submissions, a public endpoint, and an administrator
inbox.

## tech_spec.md

### Added

- **Models & Fields** — new model `odu.contact.message` (`name` Char req, `email`
  Char req, `message` Text req, `handled` Boolean default `False`), storing public
  contact-form submissions; `_order = "create_date desc"`.
- **API Endpoints** — `POST /api/contact` (`type=http`, `auth=public`, `csrf=False`):
  parses, honeypot-filters and validates a JSON `{name,email,message}` body, then
  creates an `odu.contact.message` via `sudo()`. Replaces the previous "None.".
- **Views & UI** — administrator-only **Contact Requests** inbox: list/form/search
  views, the `action_odu_contact_message` action, and the `menu_odu_contact_messages`
  menu under Settings (`base.menu_administration`, `groups="base.group_system"`).

### Changed

- **Identity & Manifest** — `data` now also loads `security/ir.model.access.csv` and
  `views/odu_contact_views.xml`.
- **Security** — added the `odu.contact.message` access rule (full CRUD for
  `base.group_system` only; public writes go through the `sudo()` endpoint).

```diff
- ## API Endpoints
- - None.
+ ## API Endpoints
+ - `POST /api/contact` — type=http, auth=public, csrf=False; stores an odu.contact.message.
```

## admin_guide.md

### Added

- New **Admin Guide** for `odu_base` (the module previously had none). Documents the
  **Contact Requests** inbox (read/triage submissions, the Handled toggle, spam notes)
  and the allowlist system parameter for administrators.
