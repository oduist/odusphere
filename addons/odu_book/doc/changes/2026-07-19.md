# 2026-07-19 — odu_book

Security and robustness hardening of the documentation renderer (security code
audit follow-up).

## tech_spec.md

### Added
- **Models & Fields (constants):** `LANG_CODE_RE`, `MAX_DOC_BYTES`, `_RENDER_CACHE`.
- **Methods & Actions:** `_render_doc_html(self, filepath, strip_marker)` — shared,
  cached, failure-isolating read+render used by both guides and the change timeline.
- **Methods & Actions (`md_to_html`):** the URL-scheme allowlist (`_safe_url`) and the
  nested-list recursion cap (`_MAX_LIST_DEPTH`).

### Changed
- **Identity & Manifest:** version `19.0.1.4.0` → `19.0.1.5.0`.
- **`md_to_html` security contract:** link/image URLs are now restricted to
  `http`/`https`/`mailto`/relative; other schemes (`javascript:`, `data:`, …) are
  rewritten to `#`. Rationale added: the HTML is injected via OWL `markup()` without
  further sanitisation, so the renderer is the sanitiser of record.
- **`_doc_lang`:** now validated against `LANG_CODE_RE`, closing a path-traversal vector
  when the language code is joined into the `doc/i18n/<lang>/` path.
- **Rendering:** now cached per file by mtime and wrapped so an oversized or unrenderable
  file is skipped instead of raising — one bad file can no longer break the whole book.

```diff
 md_to_html link/image URLs:
-  href/src taken verbatim from the source
+  href/src passed through _safe_url: only http/https/mailto/relative; else "#"
```

```diff
 _doc_lang:
   lang = (context['lang'] or user.lang or 'en').split('_')[0]
+  if not LANG_CODE_RE.match(lang): return 'en'   # no /, ., .. in a filesystem path
```

```diff
 rendering:
-  read + md_to_html on every request, no caching, unguarded
+  _render_doc_html: mtime cache + size cap (1 MB) + try/except isolation
```
