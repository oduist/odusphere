# 2026-07-02 — Documentation changes

## admin_guide.md

### Changed

- **Upstream updates — protected core modules** — rewritten for the new
  core/sphere isolation layer:
  - Template updates are pulled through the OduSphere CLI
    (`update_sphere_from_upstream`), replacing the removed `scripts/` helpers.
  - The protection is now physical, not advisory: the core lane (everything
    outside `sphere/`) is mounted read-only for the coding agent, and the CLI's
    deploy gate refuses a sphere whose core differs from the upstream template.
  - Sphere-owned paths updated to the new single `sphere/` lane:

    ```diff
    -the update keeps this sphere's `website/`, its own `odu_*` modules,
    -`README.md`, `LANG.local.md` and the sphere system map
    -`.docs/architecture.local.md`
    +everything under `sphere/` is kept: this sphere's `odu_*` modules in
    +`sphere/addons/`, `sphere/website/`, `sphere/README.md`,
    +`sphere/LANG.local.md` and the sphere system map
    +`sphere/docs/architecture.local.md`
    ```
  - The full-model reference moved from `scripts/README.md` to
    `.docs/ownership.md`.
- **Documentation languages** — the language selection file moved from the
  repo root (`LANG.local.md`) to `sphere/LANG.local.md`.
